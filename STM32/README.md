## Overview

This directory contains the STM32 microcontroller laboratory experiments performed as part of the Foundations of IoT Laboratory.

The experiments focus on embedded C programming, GPIO configuration, LED and push-button interfacing, UART communication, Wi-Fi module interfacing, HTTP communication, sensor interfacing, and MQTT-based IoT communication.

The programs are developed using STM32CubeMX, Keil µVision, and STM32 HAL drivers.

## Project Files

A typical STM32 task folder contains:

```text
TASK/
├── Core/
├── Drivers/
├── MDK-ARM/
├── .mxproject
├── TASK.ioc
├── README.md
└── circuit.png
```

**File Description:**

| File / Folder | Description |
|---|---|
| `Core/` | Application source code and header files |
| `Drivers/` | STM32 HAL and CMSIS drivers |
| `MDK-ARM/` | Keil µVision project and startup files |
| `.mxproject` | STM32CubeMX project metadata |
| `.ioc` | STM32 peripheral and pin configuration |
| `README.md` | Experiment documentation |
| `circuit.png` | Circuit diagram |

## Objective

To understand STM32 microcontroller architecture, embedded C programming, GPIO operations, peripheral interfacing, serial communication, sensor integration, and IoT communication protocols through practical laboratory experiments.

The experiments provide hands-on experience in developing embedded systems using STM32 microcontrollers and integrating hardware with software for IoT applications.
